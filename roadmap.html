Architectural Foundations of Release 1

🔒 Zero-Trust OIDC / PKCE Auth Flow
Centralized Authelia identity provider with Authorization Code Flow & PKCE (RFC 7636). Zero hardcoded domains: compile-time --dart-define injection, state/verifier CSRF validation, desktop RFC 8252 loopback receiver, and backend cryptographic JWT claims verification.
⚡ Gorilla WebSocket Engine & Persistence Contract
High-throughput Go Hub maintaining isolated ReadPump and WritePump goroutines with mutex synchronization. Mandatory persistence contract: incoming messages land in PostgreSQL before peer fan-out. Non-blocking 256-buffered channels protect against slow-client backpressure.
🔄 Dual-Tier State Hydration & Catch-Up Sync
Two-stage cache hydration via Hive NoSQL (IndexedDB on Web, file-backed on Native/Desktop) provides instant zero-latency launch. On connection, the WebSocket replays the last 50 historical messages. Catch-up sync REST endpoint (GET /api/messages/sync) bridges extended offline gaps with PostgreSQL UUID deduplication.
📱 Adaptive UI & Cross-Platform Shell
ResponsiveLayout engine with an 800.0px breakpoint dynamically renders a dual-pane layout (persistent channel/member sidebar + chat timeline) on desktop/tablet, and a stacked layout with a drawer on mobile. Strict software keyboard insets handling (SafeArea + viewInsets).

Release 3: Ephemeral Media (Self-Destruct) Future Horizon
Release 3 Architectural Strategy: Introduces privacy-centric disappearing messages and view-once media. Ephemeral state is governed by Redis TTL keyspace notifications, while binary objects are stored in an isolated MinIO S3 bucket with strict hardware lifecycle auto-purges. The client enforces hold-to-view gestures and OS screenshot deterrence.
